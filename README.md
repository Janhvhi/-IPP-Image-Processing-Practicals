## Practical 1 – Image Processing Fundamentals

Topics covered:
- Reading and displaying images using OpenCV.
- Understanding image dimensions and properties.
- Grayscale image conversion.
- Image resizing and cropping.
- Image rotation and flipping.
- HSV colour space and channel analysis.

## Practical 2 – Advanced Image Processing

Topics covered:
- Edge detection.
- Image noise and sensitivity analysis.
- RLE and Huffman compression.
- JPEG compression artefacts.
- GLCM texture analysis and segmentation.
- Multi-feature image segmentation.
